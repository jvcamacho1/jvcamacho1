## About me

I'm a Computer Engineer (UTFPR) working with data since 2022. I design, build, and optimize **batch and streaming data pipelines** on AWS and Hadoop, delivered as code with **Terraform** and **GitHub Actions**.

- 🏗️ At **GFT**, I helped democratize **60+ AWS accounts** and **200+ tables** into a client's **Data Mesh**, and built Terraform templates for Glue jobs, Lambda ingestion, and RDS snapshots.
- 🔁 At **Tata Consultancy Services**, I migrated SQL Server and SAS routines to Hadoop (Hive, Oozie) and later to **AWS Glue with PySpark**, saving **940 hours/year** of processing and automating 10+ KPIs for 7 departments.
- ☁️ AWS Certified Cloud Practitioner.
- 🌱 Currently deepening my skills in **Airflow** and **dbt**.
